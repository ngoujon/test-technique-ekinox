# Décisions d'architecture (ADR)

Chaque décision structurante est consignée dans un court document : contexte,
décision, conséquences. Une décision n'est jamais modifiée a posteriori : si elle
change, une nouvelle ADR la remplace et l'ancienne passe au statut « Remplacée ».
